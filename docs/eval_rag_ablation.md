# RAG 检索消融（baseline / hybrid / rerank）

> **性质声明**：同一份 `rag_retrieval_100.json`、同一入库年报、同一 `top_k=12`，只开关检索档位。指标是题级 **page Recall@k**、**MRR**、**nDCG@k** 和 **citation_accuracy**（top-k 去重页中 gold 页占比）。
>
> **现网生产**（2026-09-11）：Okapi BM25 + 节标题提名 `boost=3` + **`rag_max_chunks_per_page=2`**。rerank 档数字见 §6.2：Recall **79.0%** / MRR **0.4991** / nDCG **0.3364** / CiteAcc **15.48%**（run `20260911_200702_w14-cap2-boost3`）。
>
> **§2 三档消融表**仍是同日 `20260911_165959_w13-boost3`，当时 `max_chunks_per_page=0`。消融只开关 keyword / rerank，不要把 0.76 当成现网。
>
> 更早 `20260910_223219_bm25-w3-5` 无节标题提名；`20260910_160828_w3-5` 是 ILIKE + 同页=1，只作历史对照。

三档对照把「生产 Hybrid + Cross-Encoder」拆开，避免把向量召回、关键词融合、精排的贡献混成一个分数。

## 1. 三档定义

### 1.1 节标题提名为什么放在三档共同项里

`apply_section_title_boost()` 是排序后处理：chunk 的 `section_title` 命中问句里出现过的词时，名次提前 3 位（稳定排序，同名次时命中者在前）。它不改召回集合，也不依赖关键词检索或精排，所以**三档都开**——否则它的收益会被算进 hybrid / rerank 头上，消融就不干净了。

按名次挪而不是加分：RRF 分和 Cross-Encoder 分不同量纲，直接加权会把排序打乱。调用点在精排之后、`apply_page_diversity()` 之前，否则目标页可能已经被 top_k 截断掉。

## 3. 实验结论

1. **现网不要再报 0.82 / 0.74 / 0.76。** 生产路径（BM25 + RRF + Cross-Encoder + 节标题提名，`max_chunks_per_page=2`）是 Recall **0.79** / MRR **0.50** / nDCG **0.34** / CiteAcc **0.155**。§2 消融表的 0.76 是同页不限时的 rerank 档。
2. **CiteAcc 和 Recall 必须一起说。** 79% 只表示 top-12 里出现过 gold 页；去重后大约每 6–7 个检索页才有 1 页是 gold。检索很吵时 recall 仍可能为 1。
3. **这一轮召回增益几乎全在精排。** cap=0 时 0.69 → 0.70 → 0.76：hybrid 只 +1pp，rerank +6pp。上一轮（无节标题提名）是 0.66 → 0.70 → 0.74，hybrid +4pp。差别在于节标题提名把一批本来靠关键词才捞得到的页直接推进了 baseline 的 top-12，hybrid 的边际因此被吃掉。同页上限改成 2 再把 rerank 从 0.76 抬到 0.79。
4. **位次仍两边都有贡献，但代价差两个数量级。** hybrid：MRR +0.11、CiteAcc 几乎不动（11.7%→12.0%），+25 ms。rerank：MRR 再 +0.10、CiteAcc +3.8pp，P50 从 82 ms 跳到 8.8 s。合规 / 治理 / 战略类 gold 页明显前移（compliance_risk MRR 0.30→0.70）。
5. **不是单调变好，数字题尤其如此。** hybrid 救了 7 道（多为财务直读），也打掉 6 道（同比 / 治理等）；rerank 再救 12 道，但把 6 道 hybrid 已命中的数字/比率题挤出 top-12。`numeric_financial`：47.6% → **61.9%** → **52.4%**（cap=2 仍是 52.4%）。
6. **所以数字题分流问数，而不是继续堆 rerank。** 列举/分部/治理类 rerank 后到 90–100%，瓶颈不在召回；财务直读才是检索短板，应对齐 `fin_metric` / asknum。
7. **生产仍开 rerank**：交互问答更在意引用页是否靠前（CiteAcc / MRR）。批量评测、对延迟敏感的路径可以停在 hybrid。不要把 0.79 说成 Cross-Encoder 单独刷出来的。

## 4. 单项验证：车企正则 / 节标题提名 / 关键词加权

改动前关键词抽取里有一条车企正则（命中「车型 / 新推出 / 新品 / 新车」就补「上市 / 发布」）。它只覆盖车企，10 道列举题里只命中 3 道。

### 4.1 全量 100 题 · `rag_section_title_boost` 扫参（rerank 档，均已删除车企正则）

| boost | Recall@12 | MRR | nDCG@12 | CiteAcc |
|------:|----------:|----:|--------:|--------:|
| 0（关闭） | 74.0% | 0.4841 | 0.3182 | 15.51% |
| 1 | 75.0% | 0.4901 | 0.3218 | 15.64% |
| 2 | **76.0%** | 0.4974 | 0.3259 | **15.78%** |
| **3（默认）** | **76.0%** | 0.4954 | 0.3260 | 15.74% |
| 5 | **76.0%** | **0.5036** | **0.3272** | 15.69% |

- **收益在 boost=2 到顶，之后是平台期。** 2 / 3 / 5 的 Recall 完全相同；MRR 序列 0.4974 → 0.4954 → 0.5036 中间低于两边，说明这个样本量下 ±0.008 是噪声而非趋势。默认取 **3**（平台期正中）。
- **删车企正则本身是中性的，不是收益来源。** boost=0 这一档（已删正则）是 74.0 / 0.4841 / 0.3182 / 15.51%，与带正则的旧跑 `20260910_223219_bm25-w3-5`（74.0 / 0.4841 / 0.3170 / 15.42%）四项全在噪声内。**+2pp 全部来自节标题提名。** 删正则的理由是它把行业知识写死进检索层、只覆盖车企，不是它能提分。

### 4.2 product_enum 10 题（早期定向验证）

| 配置 | Recall@12 | MRR | nDCG@12 | CiteAcc |
|------|----------:|----:|--------:|--------:|
| 改动前（有车企正则、无提名） | 90.0% | 0.5310 | 0.3182 | 16.1% |
| 只删车企正则 | 90.0% | 0.5310 | 0.3295 | 17.0% |
| 删正则 + 节标题提名（**采用**） | 90.0% | **0.5560** | **0.3310** | **17.0%** |

⚠️ 这张表只有 10 题，「只删正则」那行的 nDCG +0.011 / CiteAcc +0.9pp 在 §4.1 的 100 题里没有复现。**小样本上的单项差值不要当结论用**，留在这里是为了记录当时的判断路径。

列举题关键词加权（`rag_enum_keyword_rrf_weight`，句式判断 `哪些|哪几|列举|分别是|包括|清单`）**是负收益**，nDCG −0.035、CiteAcc −4.1pp：关键词权重从 1 提到 2 之后，BM25 命中的噪声页挤掉了向量找对的页。机制和开关保留，默认值设为 `0.0`（关闭）。

## 6. 82% → 74% 的归因（一次只拧一个旋钮）

旧跑 `20260910_160828_w3-5` 是 82%，后来现网掉到 74%（节标题提名后又回到 76%）。中间同时动了四样：关键词路 ILIKE→BM25、「一页只留一条」关掉、rag-013 问法改了、cleaner/chunker 改完后重新入库。

**方法：不复现旧语料，复现旧配置。** gold 几乎没动（100 题里只有 rag-013 改了问法，gold 页仍是 `[5]`，最多贡献 1 个点）。在**今天的语料**上把配置拧回旧值，跑出一个数 X：

- 82% − X = 语料的锅（清洗 + 切段 + 重新入库 + ILIKE + rag-013）
- X − 74% = 同页截断这一个旋钮的锅

### 6.1 同页截断单独拧（boost=0，BM25，今天语料）

| 配置 | Recall@12 | MRR | nDCG@12 | CiteAcc |
|------|----------:|----:|--------:|--------:|
| 旧跑：ILIKE + 同页=1 + 旧语料 | 82.0% | 0.5295 | 0.3885 | — |
| 今天：BM25 + 同页=**1** + 新语料 | **80.0%** | 0.4974 | 0.3435 | 13.75% |
| 今天：BM25 + 同页=**0** + 新语料 | 74.0% | 0.4841 | 0.3182 | 15.51% |

**同页限制单独吃掉 6 个点；其余三样加起来只剩 2 个点。** 语料重建、换算法、改问法挤在那 2 个点的残差里，不值得再开第二个库去拆。CiteAcc 13.75% → 15.51% 是假改善：同页=1 平均命中 1.65 个 gold 页 / 12.00 个检索页，同页=0 是 1.43 / 9.46，分子其实掉了，分母缩得更狠。
