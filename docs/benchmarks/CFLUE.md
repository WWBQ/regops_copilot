# CFLUE

通义点金 / 阿里云，ACL 2024 Findings。[论文](https://aclanthology.org/2024.findings-acl.337/) · [GitHub `aliyun/cflue`](https://github.com/aliyun/cflue) · [ModelScope](https://www.modelscope.cn/datasets/tongyi_dianjin/CFLUE) · [HF `DianJin/CFLUE`](https://huggingface.co/datasets/DianJin/CFLUE)

## 能测什么

两块：

- **知识评估**：38k+ 带解析的中文金融选择题（答案预测 + 解题推理）。来源是在线模拟考试题。
- **应用评估**：16k+ 实例，覆盖分类、翻译、关系抽取、阅读理解、生成等 NLP 任务。部分来自已有共享任务，部分由金融机构数据经标注得到。

测的是「会不会中文金融知识、会不会做金融 NLP 小题」，不是「会不会检索一份指定年报」。

## 不能测什么

- A 股年报长文档 RAG、页码引用、拒答。
- 本项目的合规 DTO（条款编号、高风险置信度上限）。
- 中文监管制度在具体披露文本上的落地，而不是考场选择题。

和 w1-1 的关系：概念题（审慎监管、资本充足率层次）形态接近知识评估；**ms-02 那种「答成相邻知识点」CFLUE 平均分看不出来**。

## 语言 / 文档类型

简体中文。考题与短文本，不是 PDF 年报全文。

## 污染风险

**高。** ACL 2024、题目来自公开模拟考，2025 年 1 月全量开放。DeepSeek / Qwen 这类中文模型很可能在预训练或对齐阶段见过同类题。刷高 ≠ 本项目年报问答变强。

## 推荐用途

**题型参考 / 管线无关的外部对照。** 不拿 CFLUE 分数做能力宣称，也不接入 `eval/run_w1_chat.py`。若以后要跑，只用知识评估的 dev 看模型是否「还认识金融术语」，结果留在本地缓存。
